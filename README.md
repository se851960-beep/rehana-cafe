# ريحانة على GitHub Pages

## رفع الموقع
1. أنشئ مستودعاً جديداً على GitHub، ويفضل أن يكون عاماً إذا كنت تستخدم GitHub Free.
2. ارفع كل محتويات هذا المجلد إلى جذر المستودع، بما فيها `index.html` ومجلد `assets` وملف `.nojekyll`.
3. افتح Settings ثم Pages.
4. من Build and deployment اختر Deploy from a branch، ثم اختر الفرع `main` والمجلد `/ (root)` واحفظ.
5. انتظر انتهاء النشر. سيظهر رابط الموقع في صفحة Pages، غالباً بالشكل `https://USERNAME.github.io/REPOSITORY/`.

الموقع واجهة ثابتة وتستخدم التنقل الداخلي بالـ hash، لذلك لا تحتاج إلى خادم تطبيق إضافي.
